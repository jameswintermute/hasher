Step 1-2: Scan & Prepare
═════════════════════════

  External Source          NAS Storage           Quarantine
  (USB, Backup)            (Reference)           (Isolated)
      │                         │                    │
      ├──→ [Scan 1]             │                    │
      │   (hash import)          │                    │
      └──→ [Scan 2]             │                    │
          (hash NAS manifest)    │                    │


Step 3: Compare & Analyze
═════════════════════════

  Import             NAS              Decision Needed
    │                 │                    │
    ├─→ [Compare] ←─┤                  → [Summary]
    │                                      │
    ├─ X matches NAS       ────────────→ Option 4
    ├─ Y internal dupes    ────────────→ Option 5
    └─ Z new files        ────────────→ Option 6


Step 4: Remove Duplicates (Already on NAS)
═══════════════════════════════════════════

  Import Folder              NAS Storage      Quarantine Bin
  (Source)                   (Reference)      (Isolation)
      │                          │                │
      ├─→ [Scan for matches] ←─┤                │
      │                                          │
      ├─→ [Verify hashes]                       │
      │                                          │
      ├─→ [Propose discard] ──────────────────→ [Move here]
      │   (confirmed by user)   (never deleted)
      │
      └─→ [Keep remainder]
          (internal dupes + new)


Step 5: Dedup Within Import Only
═════════════════════════════════

  Import Folder                     Quarantine Bin
  (after step 4)                    (Growing)
      │
      ├─→ [Find duplicates within]
      │   (same content, multiple copies)
      │
      ├─→ [Rank by path length]
      │   (keep shortest)
      │
      ├─→ [Keep best copies] ─→ Remaining
      │
      └─→ [Quarantine redundant] ───→ [Move here]
          (confirmed by user)


Step 6: Move New Files to Sort
═══════════════════════════════

  Import (remaining)           /unique-files/        NAS
  (only new content)           (hand-sort folder)    (final destination)
      │                            │                    │
      ├─→ [Verify uniqueness]      │                    │
      │   (not on NAS, not dupes)   │                    │
      │                             │                    │
      └─→ [Move] ──────────────→ [Review] ──────→ [Ingest]
                              (user decision)
